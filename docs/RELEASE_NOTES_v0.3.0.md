# Desktop Orbit v0.3.0

桌面环形快捷菜单的第一个公开版本。

长按桌面空白处（或按 `Ctrl+Alt+Space`），在光标处弹出环形菜单，直接浏览、打开、搜索和拖出桌面与自定义目录里的文件。**不依赖桌面图标是否显示**——关闭「显示桌面图标」后菜单仍能列出全部文件。

## 主要功能

- **环形菜单**：扇区对应文件夹或快捷入口，悬停放大，扇区数与半径可调
- **二级下钻**：进入文件夹查看其中的文件与子文件夹，可继续下钻；右键 / `Esc` 逐级回退
- **翻页**：条目超出单环上限时折叠为 `+N`；翻页后回退先退页、再退文件夹
- **搜索**：直接在圆盘里打字，结果卡片显示查询词与命中数量，`↑` `↓` 选择、`Enter` 打开
- **拖出**：从扇区把文件拖进资源管理器、微信、浏览器上传框
- **长按唤出**：桌面空白处按住约 350ms，轮询实现，不安装全局钩子
- **关闭方式可配置**：点击外部 / 移出自动关闭（死区时间 + 边缘缓冲）/ `Esc` / 失焦
- **图形化设置面板**：分组导航 + 实时预览，改完即时生效
- **多屏与高 DPI**：Per-Monitor V2，异分辨率下不被裁切

## 已知限制

- 无法向管理员权限窗口拖放（Windows UIPI 限制）
- 按项隐藏桌面图标没有官方 API，目前提供整层开关与收纳目录两种方式
- 长按触发后那次 mouse-up 会落到桌面（仅清除图标选中，无害）
- 搜索为本地索引，尚未接入 Windows Search / Everything

## 系统要求

Windows 10 1809+ / Windows 11（x64）。不需要管理员权限，不需要安装 .NET。

## 配置文件

`%APPDATA%\DesktopOrbit\config.json`，首次启动自动生成，保存后自动热重载。
